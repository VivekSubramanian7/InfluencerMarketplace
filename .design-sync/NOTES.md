# design-sync notes — Clipline (influencer-marketplace)

- App repo, not a library: no dist. The converter needs `node_modules/influencer-marketplace` to exist — created as a Windows junction to the repo root (`New-Item -ItemType Junction -Path node_modules\influencer-marketplace -Target <repo>`). Recreate on fresh clones; it is not committed.
- Synth-entry mode from `components/ui/` (cfg.srcDir). 8 source files → 23 PascalCase exports.
- CSS: `cfg.cssEntry = .design-sync/ds-styles.css`, generated by `npx @tailwindcss/cli -i app/globals.css -o .design-sync/compiled.css`, then prepend the Google Fonts Bricolage @import and append a `:root { --font-sans: "Bricolage Grotesque", … }` block (next/font defines that var only at app runtime; without the block previews render in Times). REGENERATE this file whenever app/globals.css or component classes change, keeping both the font import and the --font-sans block.
- Fonts: Bricolage via remote Google import ([FONT_REMOTE] informational; runtimeFontPrefixes covers the rest).
- cfg.overrides.Button.cardMode = "column" (Sizes story wider than grid cells).
- SelectGroup renders blank alone — its authored preview composes the full Select (the only true render). Same applies to any future Radix sub-part.
- playwright pin: cached chromium build 1208 ⇒ playwright(-core) 1.58.x installed into .ds-sync.
- guidelinesGlob narrowed to docs/DESIGN-SYSTEM-BRIEF.md (default glob swept in TESTING.md with demo credentials and PHASE-1-SETUP.md).

## Re-sync risks
- `ds-styles.css` is generated-then-hand-amended: a re-sync that regenerates it from Tailwind MUST re-apply the font @import + --font-sans block or every preview silently reverts to Times.
- The node_modules junction is machine state; a fresh clone without it fails with ENOENT on node_modules/influencer-marketplace/package.json.
- Signature composites (creator card, deal state strip, verification badge, off-platform banner) are documented in conventions.md but NOT shipped as components — if they get extracted into components/ui later, add them to the sync scope.
- Tailwind CLI compile scans the repo; class usage added in app pages after this sync won't be in ds-styles.css until regenerated.
